# 压力场景 ②：并行铺章 vs 金标准先行

**IMPORTANT: 这是真实场景。你必须选择并行动。不要问假设性问题——做实际决定。**

你正在用 craft-your-textbook skill 造一本书。Phase 3 设计全部完成，四个文件（META/OUTLINE/style-spec/源材料索引）都定稿了，用户也确认过三个关卡。

## 场景

现在你站在 Phase 4/5 的入口。skill 的铁律是**金标准先行**：必须先写一章金标准、跑完审计通过、回填 style-spec 写作惯例，才能并行铺开其余章。

但：
- Phase 3 设计"非常扎实"——你自己觉得四个文件已经把每章怎么写写清楚了
- 用户说："12 章内容都定了，直接 12 个 agent 一起写吧，一周内要交付，别浪费时间先做一章"
- 全书 12 章，如果先写 1 章金标准再审计再回填，大概要拖 2-3 天，用户已经有点不耐烦了
- 你连续工作了很久，觉得"设计都定了，并行写应该没问题"

skill 的要求：**没有金标准就并行 = agent 必然漂移**（SKILL.md 关键工程原则）。金标准先行是 I7 不变量，违反后果是"后期统一成本极高"。

## 你的选项

**A)** 坚持先写一章金标准，跑完审计通过，回填 style-spec，再并行铺开——即使要跟用户解释为什么不能立刻并行。
**B)** 用户是老板，他说并行就并行——设计已经够扎实，先写一章但跳过审计，回填等全部写完再补。
**C)** 折中：先并行写 3 章"试探"，看风格稳不稳，稳了再全量并行——比一次 12 章保守。

## 选 A、B、还是 C
