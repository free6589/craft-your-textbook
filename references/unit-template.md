# 7 板块单元模板

每个单元按以下 7 个板块**硬顺序**组织。核心心法：**每一块要理解为"AI 老师会怎么用它"，而不是"学生读到会感受到什么"**。

```markdown
# Unit N：[标题] —— [一句话钩子]

> **本单元定位**：承接 Unit X，引入 Y。学完 AI 老师能开 30-45 分钟的课，引导学生自己推导出 Z。

---

## 🎬 场景
[一个能让学生产生疑问的具体情境，1-2 段。AI 老师开课时用这个场景切入]
[分"前段·开课钩子"（抛悬念）和"后段·收尾回响"（推导后回扣）]
[可附"文化背景兜底"：学生问某个背景时 AI 老师 30 秒带过，不展开]

## 🧭 你将学会
学完本单元，学生应该能做到：
1. [目标 1——用大白话，不是教材黑话]
2. ...

## 📌 知识锚定
[本单元核心概念/规则的精确陈述（语言类=语法/词汇规则，理科=公式/定理，文史=史实/概念定义）。AI 老师问偏了、绕晕了，靠这个兜底]
[分"必讲锚点"（45 分钟必须落地）和"兜底锚点"（学生问才讲）]

### 💬 苏格拉底引导方向
**场景激活问题**（从 🎬 场景切入）：
- [3-5 个问题]
**概念发现式追问**（引导学生自己推导规则）：
- [3-5 个问题]
**陷阱暴露问题**（针对学习者常见误区）：
- [2-8 个问题]

## 🎯 弹药库
[本单元 AI 老师随取随用的"具体案例 + 精确内容"。**内部小节按学科定制**（见下方"弹药库按学科定制"）：
 - 通用骨架：核心概念清单（含直觉解释）+ 典型例子 / 例题 / 案例 + 常用表达或公式
 - 语言类另加：词汇表（含音标、词性）、句型、语法点
 - 理科类另加：公式、定理、例题及解法、易错步骤
 - 文史类另加：关键史实/事件、人物、时间线、代表性文本片段]

## 🔗 与后续单元的连接
| 本单元知识点 | 在后续单元如何使用 | 关联强度 |
|---|---|---|

## 📐 AI 老师备课要点
[教学方法、坑型表（P1/P2/...）、课堂活动设计。AI 老师按学生状态选用]
```

## 每块给 AI 老师的用途

| 板块 | AI 老师怎么用 |
|---|---|
| 🎬 场景 | **开课台词**——上课时用这个场景切入 |
| 🧭 你将学会 | **课程目标清单**——知道今天把学生带到哪里 |
| 📌 知识锚定 | **正确答案兜底**——防止问着问着自己也不知道答案 |
| 💬 苏格拉底引导方向 | **提问路线图**（核心发明）——三类问题指引 |
| 🎯 弹药库 | **对话弹药**——核心概念、例子/例题、公式/表达随取随用 |
| 🔗 跨单元连接 | **跨节串讲素材**——提前埋伏笔，讲后面回指前面 |
| 📐 AI 老师备课要点 | **教学方法库**——坑型、节奏、活动设计 |

## 四条不可让步的设计原则

1. **非对话体**：蓝本只提供场景 + 知识点 + 提问路线图。**绝对不写死"老师说：…学生答：…"对话脚本**——AI 老师会照抄，教学就死了。
2. **💬 引导方向 = 提问路线图，不是问答**：给三类问题指引，具体措辞让 AI 老师现场发挥。
3. **📌 知识锚定 = 兜底正确答案**：有它才敢让 AI 老师自由提问。
4. **跨单元引用贯穿始终**：写 Unit 1 时就标注 Unit 2/3 会怎么用到。

## 苏格拉底引导方向的三类问题（附例）

三类问题与学科无关，下面每类各给一个语言类和一个非语言类例子。

**场景激活问题**——从 🎬 场景切入，让学生产生疑问：
> （英语）"这个对话里 Tom 说 '*I'm* 12 years old.'，但他不说 '*I* 12'。为什么中间要多一个 *am*？"
> （数学）"你分披萨给 3 个人，每人半块，为什么写成 3×½ 而不是 3+½？"

**概念发现式追问**——引导学生自己推导出规则：
> （英语）"你注意到没有，'*I am*'、'*You are*'、'*He is*'，三个主语后面跟的动词不一样。能不能猜一下 *She* 后面该跟哪个？"
> （历史）"商鞅变法前秦国最弱，变法后最强。你觉得是哪一条具体措施让农民和士兵都更卖力？"

**陷阱暴露问题**——针对学习者常见误区：
> （英语）"很多同学会写 '*He don't like apples*'，但这是错的。你知道错在哪里吗？"
> （数学）"很多人算 (-3)² 得 -9，但答案是 9。猜猜负号去哪了？"

## 弹药库按学科定制

🎯 弹药库是唯一需要按学科换内容的板块。其余六块（场景/目标/知识锚定/引导方向/跨单元连接/备课要点）对所有学科通用。

| 学科类型 | 弹药库该放什么 | 是否需要"生词维度" |
|---|---|---|
| **语言类**（英语/语文/外语） | 词汇（音标、词性、中文、例句）+ 句型 + 语法点 + 扩展词块 | ✅ 需要，读 `vocabulary-strategy.md` |
| **理科类**（数学/物理/化学） | 核心概念 + 公式/定理 + 例题及解法 + 易错步骤 | ❌ 不需要 |
| **文史类**（历史/地理/政治） | 关键史实/事件 + 人物 + 时间线/地图 + 代表性文本片段 | ❌ 不需要（可选"术语表"，无音标） |
| **技能类**（编程/实操） | 核心 API/操作 + 最小可运行示例 + 常见报错及成因 | ❌ 不需要 |

**通用骨架**（任何学科都保留）：核心概念清单（含直觉解释）+ 典型例子/例题/案例。其余小节按上表增删。

## 通用写作规范

**正文语言**：流畅中文。学科专有元素（英文单词、公式、代码、原文引文）保留原文形态，在中文里用 *斜体* 或代码块标出。**仅语言类教材**需要标音标（英式 RP，放 `/ /` 中）——其他学科不涉及音标。

**语气**：给 AI 老师读的，清晰直接。不要"本节课我们将学习……"这种空话。概念锚点处用"先让学生推理，等他自己走到某个东西，再告诉他这叫 X"。

## 禁用词清单

| 禁用 | 原因 | 替换 |
|---|---|---|
| AI（非"AI 老师"上下文） | 突兀 | "AI 老师" |
| 伴读 / 指挥官 / Socratopia | 平台术语泄漏 | 删或改"AI 老师" |
| prompt / 批量指挥 / 对话框 | 工程术语 | 删 |
| "让学生……" | 居高临下 | "引导学生……" |
| "苏格拉底"（正文频繁出现） | AI 老师会带入课堂 | 少用，改"引导式提问" |
