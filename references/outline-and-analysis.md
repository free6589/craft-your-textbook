# 分析源 MD 与设计大纲（Phase 0.5 + Phase 1）

> 拿到 MinerU 转出的 `full.md` 后，动笔写单元之前必做的两步：**读懂原始 MD、拆出大纲**。这是 Mode B（有教材）造书最容易被跳过、又最不该跳过的环节——大纲没定型就开写，并行 agent 必然各自漂移。
>
> 📎 **本文所有例子取自一本七年级英语教材，仅作示范**，且已内联在正文里，你**不需要任何外部文件**就能读懂。造别的书时，把例子里的单元名、语法点、知识链替换成你自己教材的即可。

---

## 一、MinerU 产物长什么样（先有心理预期）

`source-md/` 目录里典型有这些文件（示范教材为例）：

```
source-md/
├── full.md                      # ★ 你实际读、实际切的 markdown
├── <hash>_content_list.json     # 结构化内容列表（下游脚本可读）
├── <hash>_content_list_v2.json
├── <hash>_model.json            # MinerU 模型原始输出，造书用不上
├── layout.json                  # 版面中间产物，造书用不上
└── images/                      # 哈希命名的图片，md 里引用它们
```

**只读 `full.md`**。其余 JSON 和 images 造书阶段基本不看。

`full.md` 里你会遇到的几种真实形态，别被它们绊住：

| 现象 | 长什么样 | 怎么处理 |
|---|---|---|
| **图片破图** | `![](images/bdeb7cd...jpg)` | 正常。造书读文字，图基本不影响；需要看图时才去 images/ 找 |
| **表格被压成 HTML** | `<table><tr><td>...</td></tr></table>` | MinerU 对复杂表格的常见输出。**这些表往往是金矿**（见下节 Scope and sequence） |
| **OCR 乱码 / U+FFFD** | `�`、错字、断词（`expression1`） | 记下来，写单元时以你对该学科的知识纠正；终检阶段会扫 U+FFFD |
| **公式错乱** | 理科教材尤其多 | 转换时若没开 `enable_formula` 会更乱；以原始 PDF 为准校对 |

## 二、第一把钥匙：找到 "Scope and sequence" 总表

几乎所有正规教材的前几页都有一张**总览表**（外研版叫 `Scope and sequence`，其他教材可能叫"目录""教学计划表""课程纲要"）。**这张表是提取全书结构的第一把钥匙**——单元号、页码、标题、每单元的语法点/主题一次性全在里面。

示范教材 `full.md` 里这张表（HTML 形态）解出来就是：

```
Starter  p2   Welcome to junior high!   nouns; numbers; articles; simple present/future tense
Unit 1   p14  A new start               Reading: The first lesson    Grammar: Pronouns
Unit 2   p30  More than fun             Reading: Rock music meets...  Grammar: Simple present tense
Unit 3   p46  Family ties               ...                           Grammar: Possessive nouns
Unit 4   p62  Time to celebrate         ...                           Grammar: Adverbs of frequency
Unit 5   p78  The power of plants       ...                           Grammar: Simple future tense
Unit 6   p94  Fantastic friends         ...                           Grammar: Present continuous tense
```

有了它，`OUTLINE.md` 的"全书结构"和"逐单元语法点"就成型了一大半。**读 full.md 的第一件事就是全文搜这张表。**

## 三、定位单元边界（怎么把一大坨 MD 切成单元）

`full.md` 动辄五六千行。切单元靠两类锚点：

1. **单元标题行**：`Starter`、`## Welcome to`、`Unit 1`、单元大标题（`A new start`）等。full.md 里标题层级经常不规整（`#` 用得乱），别只靠 `#` 数量，要靠**文本内容**认边界。
2. **页码线索**：结合 Scope and sequence 里的页码（Unit 1 = p14，Unit 2 = p30……），在 full.md 里找对应内容的起止，记下**行号区间**。

产出一张"单元 → 行号区间"的对照，后面写每个单元时直接跳到对应行段读原文。

## 四、师生合版：写差异报告（Phase 0.5）

> 只有师生合版（学生用书 + 教师用书两份源）才做这一步。单一来源直接跳到第五节。

**目的**：逐单元列出教师用书比学生用书多了什么，作为后续增强各板块的依据。产出 `DIFF-STUDENT-TEACHER.md`。

### 教师用书独有的 7 类内容（每单元都有，逐一去找）

| 内容类型 | 在教师用书的标题 | 能增强蓝本哪块 |
|---|---|---|
| ① 单元话题深度解读 | `## 1 单元话题` | 🎬 场景的立意 |
| ② 语篇内容清单 | `## 2 语篇内容` | 🎯 弹药库（核心词汇/体裁） |
| ③ 学情分析 | `## 二、学情分析` | 💬 陷阱暴露问题 + 📐 坑型 |
| ④ 教学要求 + 评价标准 | `## 三、教学要求` | 🧭 你将学会 + 📐 教学节奏 |
| ⑤ 教学提示（最核心） | `## 教学提示：xxx` | 📐 AI 老师备课要点（每单元 5-12 个） |
| ⑥ 语法学习详解 | `## 语法学习` / `## 语法复习` | 📌 知识锚定 |
| ⑦ 背景提示 | `## 背景提示：xxx` | 🎬 文化背景兜底 |

### 差异报告每单元一节，固定结构

```markdown
## Unit N：[标题]（教师用书 L行号-L行号）
### 教师用书独有内容
- ① 单元话题：...
- ③ 学情分析：学生小学已学 X，易错 Y
- ⑤ 教学提示清单（N 个）：教学提示：xxx / 教学提示：yyy ...
- ⑥ 语法详解：...
### 可增强板块清单
| 蓝本板块 | 可吸收内容 | 增强方式 |
| 🎬 场景 | 话题立意 | 补文化背景兜底 |
| 📌 知识锚定 | 语法详解 | 追加精确归类 |
```

### ⚠️ 单元顺序可能不一致（真实的坑）

举个真实例子：某套七年级英语教材的教师用书（较早版本）**Unit 5/6 顺序与学生用书（较新版本）相反**——教师用书里 "Fantastic friends" 是 Unit 5、"The power of plants" 是 Unit 6。

**规则：一律以学生用书顺序为准，从教师用书取内容时按"话题匹配"而非"编号匹配"。** 差异报告里每单元都标清楚对应的教师用书行号区间和编号映射，避免张冠李戴。

## 五、设计大纲（Phase 1）：OUTLINE.md 的五项

大纲必须包含五项，缺一不可。下面用示范教材的真实内容逐项举例：

### ① 模块划分 + 页码定位（"全书结构"）

用 ASCII 树把 Starter + 各 Unit 列出，每个标页码 + 主题 + Reading + Grammar。直接来自 Scope and sequence。

### ② 全书知识链（一句话推理主线）

**这是大纲的灵魂**——用一条线说清从第一单元到最后单元知识怎么流动。示范教材的链：

```
Starter（工具库：名词/数字/冠词/there be/一般现在时预告）
  → Unit 1 代词（句子主语打底）
  → Unit 2 一般现在时（最基础时态，后续都对照它）
  → Unit 3 名词所有格（表"拥有"）
  → Unit 4 频度副词（叠加在一般现在时上）
  → Unit 5 一般将来时（与一般现在时对照：现在 vs 将来）
  → Unit 6 现在进行时（与一般现在时对照：习惯 vs 此刻）
```

写的时候给每个单元一句"定位"：为什么它在这个位置、承接谁、为谁打底。

### ③ 逐单元知识点"含义三问"

每个核心知识点都要答三问，**不能只列标题**：

- **是什么**：一般现在时 = 描述习惯和事实的时态
- **为什么重要**：英语最基础时态，几乎所有后续时态都与它对照
- **直觉是什么**：`I have a book`（我有本书），`He likes music`（注意三单 -s）

把这些整理进"知识点表"，每个知识点配页码 + 直觉解释。

### ④ 跨单元关联表（核心）

**决定 AI 老师能不能跨节串讲**——没有它，AI 老师只能孤立讲一节。两张表：

**语法点跨单元关联**：
| 本单元语法 | 在后续单元如何使用/对照 | 关联强度 |
|---|---|---|
| Unit 1 代词（主格） | Unit 2 主谓一致要用；Unit 6 现在进行时主语位置 | 强 |
| Unit 2 一般现在时 | Unit 4 频度副词叠加其上；Unit 5/6 时态对照 | 强 |

**主题与功能跨单元关联**：每单元的主题、语言功能、以及"→ 下一单元怎么接"的串讲线索。

> 这张表要和后面每个单元的 🔗 板块**一致**（Phase 5 跨单元审计会核对）。

### ⑤ 全局思维导图（ASCII）

把知识链 + 关联表画成一张 ASCII 图，一眼看清哪个知识点辐射到哪些单元。例：

```
Unit 2: 一般现在时
  ├─ 动词三单 ────────→ Unit 6 现在进行时 be 动词变化
  ├─ do/does 否定疑问 ─→ Unit 4 频度提问
  └─ 描述习惯 ────────→ Unit 4 频度副词叠加
```

### 大纲审核 Checklist

写完 OUTLINE.md 逐条核对：

- [ ] 单元划分与原教材 Scope and sequence 一致
- [ ] 每个知识点有"含义三问"
- [ ] 跨单元关联表覆盖主要逻辑链路
- [ ] 思维导图完整展示知识流动
- [ ] 编写顺序合理（通常按教材顺序，让学生跟学校进度）
- [ ] 心理排演：拿大纲能开出一节课吗？（如"Starter 的场景可以是开学第一天……"）

## 六、顺带定稿 META.md

大纲定型的同时，把写作规范 `META.md` 也定下来（7 板块模板、禁用词、生词策略等——见 `unit-template.md`）。**OUTLINE.md + META.md 双双定稿，才是"可以开始并行写单元"的信号。**

## 七、附录怎么写（Phase 4 收网）

单元全部写完后，附录把散落各单元的东西汇总成"全书速查表"。附录**不用 7 板块模板**——它是索引/清单，不是教学单元。常见两类附录（放 `appendix/appendix-*.md`）：

**① 核心概念/术语总表**（`appendix-A-*.md`）——把各单元 🎯 弹药库的核心项汇总，按主题或单元分组，每条固定字段：

| 术语/概念 | 所在单元 | 精确定义 | 直觉/一句话 |
|---|---|---|---|
| 一般现在时 | Unit 2 | 描述习惯与事实的时态 | I have… / He likes…（注意三单 -s） |

（语言类可再拆词汇表：英文 / 音标 / 词性 / 中文 / 例句——同 `unit-template.md` 的词汇表字段。）

**② 知识点/规则总览**（`appendix-B-*.md`）——把各单元 📌 知识锚定的语法/公式/定理规则汇总成一张递进表，配跨单元链条（同 OUTLINE.md 的知识链，但更细）。

**写附录的原则**：
- 只汇总、不新增——附录里的每一条都应在某个单元正文出现过，附录是"再查一遍"的入口，不是新知识
- 对照来源逐条查漏：语言类对照教师用书各单元 key vocabulary 补遗漏词条；理科对照各单元公式/定理；若有听力/音频原文，可加"听力原文索引"
- 附录也要过 Phase 8 拆脚手架——不留"本附录 v2 新增"这类过程元数据

---

**一句话**：读 full.md 先抓 Scope and sequence 总表 → 切出单元行号区间 →（师生合版）逐单元写差异报告 → 把结构/知识链/含义三问/跨单元关联表/思维导图落成 OUTLINE.md → 定稿 META.md → 写单元 → 附录收网汇总各单元弹药库与知识锚定。大纲没五项定型，不要动笔写单元。
